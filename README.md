# KIDANE

Personal operating system for goals, daily actions, MMCD business metrics and health tracking.

## V0.1
- Supabase authentication
- Persistent goals and daily actions
- Supplement checklist
- Business dashboard
- Health dashboard
- Natural-language quick logging for common daily metrics
- Goal → daily action generation

Backend: Supabase
Deployment target: Vercel

> Apple Health, Screen Time, Stripe, Instagram and full AI parsing are subsequent integration phases.
